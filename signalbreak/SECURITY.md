# Security Policy

SignalBreak is designed for defensive malware research and detection engineering.

Please do not open untrusted samples on a normal workstation. The repository contains only synthetic snapshot fixtures. For real malware, use an isolated analysis environment and follow your organization's malware-handling procedures.

## Scope

The core project is static-only. It does not intentionally execute samples, download payloads, or modify binaries.

## Reporting a vulnerability

For code vulnerabilities in SignalBreak, open a private security report through GitHub where available. Do not upload live malware or sensitive enterprise samples to a public issue.
